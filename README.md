# BookHaven — A New World on Every Page

## About the Project
BookHaven is a book recommendation website designed to help readers discover their next favourite book. It was created as part of a Web Technologies Lab project.

## Features
- Explore book recommendations
- Discover different book genres
- Browse books and their details
- Interact with authors and other readers
- Simple and user-friendly interface

## Technologies Used
- HTML5
- CSS3
